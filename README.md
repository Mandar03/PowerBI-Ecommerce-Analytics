# 📊 E-Commerce Sales Analytics Dashboard (Power BI)

## 🚀 Project Overview
This project analyzes an e-commerce dataset to uncover insights into sales performance, customer behavior, delivery efficiency, and product profitability.

Built using Power BI with real-world data modeling and business-focused KPIs.

---

## 🎯 Business Goals
- Monitor revenue performance
- Identify delivery delays
- Analyze customer satisfaction
- Track product category performance
- Understand time-based sales trends

---

## 📂 Dataset

This project uses the Olist Brazilian E-commerce public dataset.

Dataset Source:
👉 https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

Tables used:
- Orders
- Order Items
- Customers
- Payments
- Reviews
- Products

---

## 🧠 Data Model
Star schema model with Orders as central fact table.

---

## 📊 Dashboard Pages

### 1️⃣ Sales Overview
Revenue trends, regional performance, KPIs.

### 2️⃣ Customer & Delivery Insights
Delivery performance vs review score analysis.

### 3️⃣ Product Performance
Category revenue and freight cost analysis.

### 4️⃣ Time Analysis
Monthly trends and growth patterns.

---

## ⚙️ Tools Used
- Power BI
- DAX
- Data Modeling

---

## 💡 Key Insights
- Late deliveries correlate with lower customer ratings.
- Certain categories drive high revenue but also high freight costs.
